## 1. 감사 방법과 그 결과의 신뢰도

9개 영역(보안·인프라·프롬프트 인젝션·시세·뉴스·거시·오정보·법적노출·가용성)을 병렬 감사하고, **모든 지적을 두 명이 따로 검증**했습니다. 한 명은 "이 지적을 반증하라"는 임무였고, 다른 한 명은 운영자 관점에서 "이게 실제 방송에서 문제가 되는가"를 판정했습니다.

```
원시 수집    194건
  ├ 반증     96건   (49.5%)
  └ 생존     71건   (36.6%)
       └ "실제로 방송에 문제 된다"  51건
```

**반증된 96건이 이 리포트에서 가장 중요한 숫자입니다.** 검증 없이 194건을 드렸다면 절반이 허수였습니다. 실제로 걸러진 것들:

| 지적 | 반증 사유 |
|---|---|
| RSS 헤드라인이 사이렌 검증기 프롬프트에 그대로 삽입된다 | 삽입은 사실이나 분류기 출력이 2값이라 인젝션이 성공해도 **얻을 게 없다** |
| 오버레이가 안 쓰는 Claude OAuth 토큰을 들고 있다 | **전제가 조작됨** — `$env/dynamic/private` 를 import 한다는 주장이 거짓 |
| `level` 미검증으로 토스트에 `undefined` 가 찍힌다 | JSON 경계에서 `null` 이 되고 기존 clamp 가 처리 |
| `robots.txt` 가 `/control` 크롤링을 허용한다 | 인용은 정확하나 인과가 4군데에서 끊김 |
| 정적 자산이 hooks 앞에서 서빙돼 404 은폐가 깨진다 | 기제는 실재하나 **노출되는 내용이 비어 있음** |

이 리포트의 71건은 전부 이 관문을 통과했고, 각 항목의 **수정안은 검증자가 원안을 고친 최종본**입니다.

또한 제가 프로덕션에서 직접 확인한 것 하나를 정정해 둡니다. 처음에 `/control` 이 전 세계에 열려 있다고 판단했으나, `/whoami` 로 확인한 결과 IP 게이트가 **정상 작동 중이고 이 맥이 허용목록에 있어서** 통과한 것이었습니다. 지금 세계에 열려 있지는 않습니다. 다만 아래 #6 의 이유로 언제든 열릴 수 있습니다.

## 2. 시나리오

### 시나리오 A — 가짜뉴스가 방송 최상단에 오르는 경로

**이 시나리오는 가설이 아닙니다. 어제 이 시스템에서 이미 일어났습니다.**

어제 `economy.ac` 라는 처음 보는 사이트의 글이 실제로 TOP STORY 자리를 차지했습니다. 악의가 없는 SEO 글이었을 뿐, **경로는 완전히 동일합니다.**

```
1. 공격자가 구글 뉴스가 색인하는 아무 사이트에 글을 올린다
     매체명을 "CNBC Markets Daily" 로 등록      → #35 isMajorOutlet 은 부분문자열 매칭
                                                   \b(cnbc)\b 가 걸려 +0.75 획득
                                                   ("ft-markets.com", "reuters-wire.net" 도 실측 확인)

2. 제목:  "Fed announces emergency rate cut as S&P 500 futures plunge 4.2% on tariff shock"
     scoreNews          → 'rate cut' + 'tariff' 로 level 5
     marketEventScore   → 방향동사 'plunge' + 폭 '4.2%' → 1.0        (내가 어제 넣은 가점)
     isAnalysisForm     → 물음표 없음, 통과
     isPressRelease     → 통과
     isBlockedPublisher → 목록에 없는 새 도메인, 통과

3. <pubDate> 를 30일 뒤로 찍는다                → #13/#17 상한이 없다
     decay = level + 0.75 + 1.0 − (음수)/6 → 사실상 무한대
     모든 슬롯을 영구히 점유한다

4. 진짜 기사를 지운다                            → #38/#44 최신순 병합
     진짜 CNBC 기사와 토큰 유사도 0.55 를 넘으므로
     "더 새로운" 가짜가 대표가 되고 원본은 배열에서 삭제된다

5. TOP STORY 에 오르고 동시에 BREAKING 사이렌이 울린다
     level 5 + 45분 이내 → 조건 충족

6. 사이렌 검증기를 무력화한다                    → #36 4곳에서 fail-open
     동시성이 1이므로, 앞서 다른 헤드라인 6~10건을 먼저 흘려보내면
     검증기가 밀려 "verifier busy" → 그대로 통과

7. 화면에 남는다                                  → #22 AUTO_DISMISS_MS = 0
     새 level≥4 가 오거나 사람이 /control 에서 끌 때까지 무기한
     새벽 2시에는 아무도 안 보고 있다
```

**약한 고리** — 3번(미래 pubDate)이 가장 강력하지만, 구글 뉴스가 미래 날짜를 그대로 전달하는지는 매체마다 다릅니다. 다만 3번이 막혀도 1·2번만으로 충분합니다. `economy.ac` 가 그 증거입니다.

**끊는 방법** (비용 순): `rss.ts:65` 에 `when > Date.now() + 120_000` 이면 버리는 한 줄 → `isMajorOutlet` 을 표시명 부분매칭이 아니라 `<source url>` 도메인 전체 매칭으로 → BREAKING 에 자기 만료 시간 부여 → 단일 매체 단독 보도는 TOP STORY 최상단 자격 제외(교차 확인 요구).

### 시나리오 B — 오정보를 실어 나르는 채널이 되는 경로

시세조작에 **능동적으로** 쓰이기는 생각보다 어렵습니다. MARKET FOCUS 는 메가캡 유니버스로 제한돼 있고, Auto-Sniper 가 바꿀 수 있는 차트는 `WATCHED` 선물 목록뿐이라 임의 소형주를 화면에 띄울 수 없습니다. 그 점은 방어가 잘 돼 있습니다.

**현실적인 위험은 반대 방향입니다 — 운영자가 의도치 않게 오정보 발행자가 되는 것.**

```
FOMC 발표 14:00 ET.  그 직전 Finviz 가 403 을 뱉기 시작한다   → #3 캐시 최대 나이 없음

  · getFutures 가 마지막 성공 Map 을 영원히 반환
  · live 플래그는 시세 나이가 아니라 벽시계에서 나온다        → 전부 "지금 값"으로 표시
  · 헤더의 NASDAQ FUT · S&P FUT · GOLD · OIL · VIX 가
    13:55 값에 멈춘 채 완전한 밝기로 계속 방송된다

발표가 나오고 시장이 1.5% 움직인다. 화면은 0.0% 를 보여준다.
시청자는 이 방송을 보며 매매하고 있다.
```

여기에 결정적인 문제가 겹칩니다. **시세와 헤드라인의 모순을 잡는 `contradictsLive` 가 바로 그 얼어붙은 Finviz 값을 기준으로 판정합니다.** 즉 데이터가 죽으면 오정보 방어막도 같이 죽습니다.

`whatViewerSees` 관점에서 최악은 이겁니다 — **화면이 내부적으로 완벽하게 일관됩니다.** 시청자가 이상을 감지할 단서가 없습니다.

**끊는 방법**: `finviz.ts` 의 4개 폴백 반환에 나이 상한을 걸고(m5 는 5분), `live` 를 벽시계가 아니라 **시세 나이**에서 파생시킵니다. 나이를 화면에 드러내는 게 핵심입니다 — 이 저장소가 헤더 `·FRI` 태그로 이미 하고 있는 것을 선물에도 적용하는 것뿐입니다.

### 시나리오 D — 실투자자에게 쓸모가 있는가

정직하게 답하겠습니다.

**진짜 가치가 있는 것 (무료 대안이 드묾)**

- **24시간 나스닥 선물 곡선 + 전일 정산가 기준선.** TradingView 무료 임베드가 선물을 못 그리는데 이건 그립니다. 야간·주말 흐름을 한 화면에서 보는 건 실제로 쓸모가 있습니다.
- **TAPE READ 의 "지난 30분".** 다른 어떤 무료 화면도 당일 누적과 직전 구간을 나란히 보여주지 않습니다. 어제 넣은 `RECOVERED 48% OF TODAY'S DROP` 같은 줄이 정확히 그 가치입니다.
- **세션 구분의 정직함.** `·FRI` 태그, `FUT`/`ETF` 구분, `spot · 24/7` — 이걸 제대로 하는 무료 화면이 거의 없습니다. 이 프로젝트에서 가장 잘한 부분입니다.

**중립적 배경 (있어도 그만)**

- US ECONOMY(FRED) 패널 — 월 단위 데이터라 24시간 방송에서 하루에 한 번도 안 바뀝니다.
- UPCOMING 일정 — 유용하지만 무료 대안이 넘칩니다.
- 음악 플레이어, 하단 티커.

**적극적으로 해로울 수 있는 것**

- **MARKET DRIVER 의 고정 인과 문장.** `THEME_NOTE` 는 주제별 고정 문장인데, 그 옆에 붙는 자산이 **주제와 무관하게 절대 등락률 순으로 채워집니다**(#26). "FED" 테마 옆에 비트코인 +4% 가 붙으면 화면은 연준 때문에 비트코인이 올랐다고 말하는 셈입니다.
- **BEAT/MISS 배지**(#58)와 **거시 actual/consensus**(#21, #23) — LLM 출력이 검증 없이 특정 기업·지표에 대한 사실 주장으로 나갑니다. 실적 반응률은 검증 체계를 만들어 뒀는데, 이 둘은 안 만들었습니다.
- **`▼ vs prev` 가 값이 같을 때도 하락 색으로 표시**(#18, #54) — 실업률이 4.1% → 4.1% 로 변화가 없는데 화면은 "내렸다"고 말합니다.

**한 가지만 고친다면**: MARKET DRIVER 의 무관 자산 백필(#26)을 지우십시오. 짧은 줄은 정직하지만, 무관한 줄은 **인과 주장**입니다. 이 시스템 전체에서 "측정하지 않은 원인을 말하지 않는다"는 원칙을 유일하게 위반하는 자리입니다.
